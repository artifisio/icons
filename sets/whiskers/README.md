# Whiskers

**[Open in the gallery →](https://artifisio.github.io/icons/whiskers/)**

## Install

```bash
npx artifisio add whiskers --kind icon
```

Recolour at install time; themeable slots: `ink`.

```bash
npx artifisio add whiskers --kind icon --colors "ink=#4A7CFF"
```
